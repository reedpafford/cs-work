## Notion page shape
**Notion page shape** every video variation page has three callouts and nothing else: Text Hook (Reed writes) · Script (hook line first, then the body, one beat per line) · Page: Palace Guard + Primary Text (condensed script for that variation, ends with 👉 lander). **A prehook variation has four (Reed, JC38, 2026-09-22):** a `Pre hook Text Hook` + `PreHook` callout above the three, holding the prehook's plate and the spoken prehook line, and the Script starts on the plain hook. **An LFS page has two:** the Text Hook callout is deleted, the Script callout holds the whole post, and the third callout keeps only `Page: Palace Guard` (the Primary Text line is deleted, because the post is the primary text) (Reed, 2026-09-16). An LFS post is spaced for paste: one thought per paragraph and a blank block between every paragraph, written as a zero-width-space line because the connector drops empty lines (`finalize.md` step 4). Every script draft goes on the V1 Script callout as soon as it passes the scanner, so Reed can edit it by hand (Reed, 2026-09-11). The scratchpad only holds the scanner's copy. Options, flags and reasoning stay in chat.
